# Yeast Rush (GGJ 2026)

**Yeast Rush** is a fast-paced fermentation mini **VR game** developed for **Global Game Jam 2026**.  
Players control a yeast cell racing against time to convert sugar into ethanol while avoiding contamination, heat stress, and environmental hazards.

---

## Project Info

- **Game Name:** Yeast Rush  
- **Event:** Global Game Jam 2026  
- **Engine:** Unity  
- **Unity Version:** **6000.2.7f2**
- - **Platform Target:** VR  
- **Primary Device:** **HTC Vive Focus Vision**  
- **XR Framework:** OpenXR
